I want you to create a complete web app concept and first implementation for a fun football app that we will use with friends.

The app is for our weekly football matches. The main goal is to make it easy and fun to manage games, seasons, teams, scores, goals, assists, standings, and player stats.

You have full freedom to make product, UX, design, and technical decisions. I want you to think like a great product designer, frontend engineer, and sports app founder. Do not just build basic CRUD screens. Make it feel polished, modern, playful, and exciting to use.

Core idea

We play football with friends and want a beautiful app where we can:

Create seasons
Create players
Create teams
Customize teams with names, colors, badges, and maybe funny identities
Create matches with date, location, teams, and final score
Track goals and assists by player
See standings
See top scorers
See top assists
See match history
See player profiles and stats
Randomly draw teams
Keep the same drawn teams together for 4 weeks by default
Allow changing or reshuffling teams when needed
Make the whole experience feel fun, social, and competitive

Important product direction

The app should feel like something we actually want to open after every match.

Think about features like:

A home dashboard with next match, current season, leaderboard, and highlights
A matchday screen where we can quickly add score, goals, assists, and MVP
A team draw screen that feels exciting and visual
A season table with points, wins, draws, losses, goals scored, goals conceded, and goal difference
A player ranking screen with goals, assists, MVPs, win rate, and maybe funny badges
A team customization screen
A match calendar with dates and places
A fun visual identity, not boring or corporate
Nice empty states
Nice animations where useful
Mobile first responsive design
A design that works well on desktop too

Team draw logic

The app should support drawing teams randomly.

Rules to consider:

Players can be selected for the match
Teams are generated from selected players
Teams should stay together for 4 weeks by default
After 4 weeks, the app can suggest a reshuffle
The user can manually reshuffle anytime
The app should allow editing teams manually after the draw
Try to make the draw balanced if you decide to add skill levels
If you think skill levels make sense, add them
If you think positions make sense, add them
You are free to decide the best approach

Design direction

Make it beautiful, modern, and fun.

Avoid a generic admin dashboard feeling.

Use a football inspired visual style, but still clean and premium.

You can choose colors, typography, layout, components, visual effects, cards, gradients, illustrations, badges, icons, and microinteractions.

The app can have a playful vibe, like a mix of sports league app, fantasy football, and friends group competition.

Technical direction

You can use React.

You are free to choose the best structure, components, state approach, and data model for this prototype.

For now, local state or local storage is fine unless you think another approach is better.
